# Техническое задание — «Учебный планер»

## 1. Что это
Веб-приложение с REST API для хранения учебных задач и отслеживания сроков. Данные хранятся в SQLite; интерфейс — адаптивная HTML-страница. Первая версия рассчитана на одного пользователя, а сущность пользователя включена в целевую схему для последующего развития.

## 2. Для кого
Для студентов, которым нужно собирать задания и дедлайны в одном месте, видеть текущий статус работы и не забывать о ближайших сроках.

## 3. Основные функции
- Создание, просмотр, редактирование и удаление задач.
- Название, описание, необязательный дедлайн и статус задачи: `planned`, `in_progress` или `done`.
- Фильтрация задач по статусу; в целевой версии — также по владельцу.
- CRUD профиля пользователя в целевом API-контракте. Регистрация, вход и защита endpoints авторизацией не входят в первую версию.

## 4. Сущности
- **User (пользователь):** `id`, `name`, уникальный `email`, `created_at`, `updated_at`.
- **Task (задача):** `id`, `user_id`, `title`, `description`, `due_date`, `status`, `created_at`, `updated_at`. Каждая задача принадлежит одному пользователю; у пользователя может быть много задач. При удалении пользователя его задачи удаляются каскадно.

## 5. Стек
Python 3.12 · FastAPI · SQLite · HTML/CSS/JavaScript · Docker · GitHub Actions · pytest.
